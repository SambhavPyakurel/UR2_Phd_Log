# Project Progress Log

## Week 1

We connected an ultrasonic sensor to an Arduino and programmed it to measure the distance to an object. We placed the object at six distances—5, 10, 15, 20, 25, and 30 cm—and collected 100 readings at each position, for a total of 600 readings per complete experiment.

We also developed Python scripts to receive the readings from the Arduino and save them as CSV files. These scripts generate graphs comparing the measured distances with the actual distances, along with measurement-error graphs and summary statistics. This allows us to evaluate how accurate and consistent the sensor readings are at each distance.
